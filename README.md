# 罗德指数

React + TypeScript + Vite 的《明日方舟》干员创作热度网站。434 份档案和头像来自 [PRTS](https://prts.wiki/w/干员一览)。参考 Kuro 的侧栏、灰白背景、留白和细线布局。

**仅在本机运行，不部署。网站源码可备份至用户指定的 GitHub 私有仓库；采集脚本单独维护在 `collectors` 分支。原始采集数据、统计快照、数据库、断点、登录凭据与日志仅保存在本机。**

私有仓库包含网站源码、测试、依赖清单与运行文档，以及网站运行所需的静态干员目录 `public/data/operators.json` 和头像。静态干员目录用于角色识别和标签配置，不包含采集到的作品或平台互动指标。首次上传采用当前源码的独立快照，不携带旧 Git 历史或 `.openai` 托管配置，也不启用自动部署。

## 运行网站

```powershell
npm install
npm run dev
```

打开终端输出的本机地址。网站具备 10 个平台入口，年度分色条形图／热力图、点赞／观看量切换、职业／阵营／性别筛选、干员详情与来源、关注和 JSON／CSV 导出。

## 哔哩哔哩与 LOFTER 标签统计页面

哔哩哔哩展示已核验的多标签交集作品数，采集中或截断显示“部分”。详情展示必需标签、已检查／排除记录、来源和时间；仅为搜索可返回范围，不声称全站总量。LOFTER 展示现有中文标签的参与与浏览，可切换指标；万、亿或加号保留平台原文并标为约数，参与不冒充去重作品总数。两个页面均支持搜索、职业／阵营等筛选、独立联动开关、排序、关注、详情与CSV导出，不套用年度点赞／观看量图表。

统计数据仅保存在本机，页面每 5 秒读取 `/api/<平台>/tag-counts`，静态回退为对应 JSON。B站阿米娅各形态分别匹配中文标签，仅归一化全半角与大小写，不借用本体数量。

## 森空岛话题排行

森空岛默认按话题累计浏览量排序，可切换到发帖数。详情保留浏览、发帖、讨论、话题来源、发布时间和采集时间。共用话题在排行只显示一次，未取得的指标留空。

从本地 `collectors` 工作树运行 `scripts/skland_collect.py`，用 `--workspace` 指向网站目录。脚本把快照保存到 `.local/skland/topic-counts.json`，由 `npm run dev` 启动的本机网站读取。

## 统计口径

数据文件仅保存在本机 `.local/` 与 `public/data/`（均不提交到版本库），网站约每 4 秒刷新。

每个平台作品对同一干员只计一次；一件作品关联多位干员时分别计入对应干员。年份按作品发布时间（北京时间）分组，数值是观察时累计互动，**不是当年新增互动**。收藏、转发和平台综合热度不能替代点赞。精确计数缺失或只有“1.2万”等缩写时为 null，不能冒充 0。

“已取完”表示配置的标签接口已经返回结束。重复分页、提前截断、声明数量与实际数量不符、详情失败或访问受限，均不标记为已取完。平台未返回、私密、删除作品或未知昵称标签无法据此保证覆盖；总体完成前界面继续明确显示部分覆盖。


## 主要代码

- `server/http-plugin.ts`：仅本机的网站快照与统计接口。
- `src/CollectionPanel.tsx`、`src/useLiveData.ts`：采集状态与快照读取。
- `src/domain.ts`：筛选、年度汇总、导入与 CSV。

保留的 `.openai/hosting.json` 仅用于识别此前托管项目，不构成任何新的上传或部署授权。
